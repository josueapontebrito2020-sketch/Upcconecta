# Ícono de la app

Archivos fuente del ícono de UpcConecta (hechos a partir de
`assets/images/logo_upc_conecta.png`):

- `app_icon.png` — ícono completo 1024×1024 (iOS, web, Android antiguo).
- `app_icon_foreground.png` — logo sobre fondo transparente (capa delantera del
  ícono adaptativo de Android 8+).
- `app_icon_background.png` — fondo blanco con verde claro (capa trasera).

Los tamaños finales ya están copiados en `android/app/src/main/res/mipmap-*`,
`ios/Runner/Assets.xcassets/AppIcon.appiconset` y `web/`.
